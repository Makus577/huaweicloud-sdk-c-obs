# 国密+双向认证测试代码说明

## 概述

本文档描述了为国密(GM)和双向认证(Mutual Authentication)功能实现的测试代码。

## 测试代码结构

### 1. 测试框架 (Test Framework)

**文件:**
- `ssl_gm_test_framework.h` (493行) - 测试框架头文件
- `ssl_gm_test_framework.c` (765行) - 测试框架实现

**功能:**
- 测试用例和测试套件管理
- 断言宏 (TEST_ASSERT, TEST_ASSERT_EQ等)
- 测试日志和彩色输出
- 证书文件工具
- 文件操作工具 (MD5计算,文件比较等)
- SSL/TLS功能检测

### 2. 测试场景 (Test Scenarios)

#### 场景1: 标准TLS双向认证测试
**文件:** `test_scenario_1_standard_tls.c` (271行)

**测试用例:**
- `test_tls_1_2_mutual_auth` - TLS 1.2双向认证
- `test_tls_1_3_mutual_auth` - TLS 1.3双向认证
- `test_password_protected_key` - 密码保护私钥
- `test_client_cert_verification` - 客户端证书验证
- `test_cipher_suite_config` - 密码套件配置
- `test_mutual_auth_without_cert` - 缺少证书的错误处理

#### 场景2: 国密单向认证测试
**文件:** `test_scenario_2_gm_one_way.c` (317行)

**测试用例:**
- `test_gm_support_available` - GM支持检测
- `test_gm_mode_enable` - GM模式启用
- `test_gm_cipher_suite_config` - GM密码套件配置
- `test_gm_tls_1_2_enforcement` - TLS 1.2强制
- `test_gm_only_mode` - 仅GM模式
- `test_tongsuo_detection` - Tongsuo库检测
- `test_gm_cipher_availability` - GM密码套件可用性

#### 场景3: 国密双向双证书测试
**文件:** `test_scenario_3_gm_mutual_dual_cert.c` (359行)

**测试用例:**
- `test_gm_dual_cert_config` - 双证书配置
- `test_gm_missing_enc_cert` - 缺少加密证书处理
- `test_gm_with_tls_1_3` - TLS 1.3与GM兼容性
- `test_sign_vs_enc_cert_usage` - 签名vs加密证书使用
- `test_error_handling_missing_certs` - 证书缺失错误处理
- `test_dual_cert_with_password` - 密码保护的双证书

#### 场景4: 国密密码套件配置测试
**文件:** `test_scenario_4_gm_cipher_suite.c` (332行)

**测试用例:**
- `test_custom_cipher_string` - 自定义密码字符串
- `test_default_cipher_selection` - 默认密码选择
- `test_invalid_cipher_string` - 无效密码字符串处理
- `test_cipher_priority_ordering` - 密码优先级排序
- `test_cipher_with_mutual_auth` - 带双向认证的密码配置
- `test_empty_cipher_list` - 空密码列表处理

## 编译说明

由于测试代码依赖OBS SDK的实际接口定义，编译时可能遇到链接问题。建议的编译步骤：

1. 创建build目录:
```bash
mkdir build && cd build
```

2. 运行CMake配置:
```bash
cmake ..
```

3. 编译测试:
```bash
make
```

## 运行测试

编译成功后，可以运行单个测试场景:

```bash
./test_scenario_1_standard_tls  # 场景1: 标准TLS双向认证
./test_scenario_2_gm_one_way     # 场景2: 国密单向认证
./test_scenario_3_gm_mutual_dual_cert  # 场景3: 国密双向双证书
./test_scenario_4_gm_cipher_suite      # 场景4: 国密密码套件配置
```

## 注意事项

1. 测试代码使用桩(stub)实现OBS SDK函数，实际运行时需要与真实的OBS SDK库链接
2. 国密(GM)测试需要Tongsuo或支持SM2/SM3/SM4的OpenSSL版本
3. 部分测试用例需要证书文件支持
